## 先聊聊"回程"这件事：为什么它比去程更折腾人

很多人买香港 VPS 的时候，盯着去程看——"电信去程走 CN2，不错啊"。买回去一用，晚上高峰期卡成幻灯片，开始怀疑人生。

问题大概率出在**回程**上。

简单打个比方：去程是你从家出发去公司走的路，回程是你下班回家走的路。去程走了高速公路，回程挤上了晚高峰的国道，那回家的体验能好吗？VPS 也一样——你的用户从大陆访问香港服务器（去程）可能走的是优质线路，但服务器把数据传回大陆（回程）如果走的是拥堵的普通 BGP 出口，那延迟、丢包、速度全都会拉垮。

这就是为什么老玩家选香港 VPS，开口第一句问的往往是："**回程走什么线路？三网回程都优化了吗？**"

目前主流的回程优化方案，围绕三大运营商的精品线路展开：

- **CN2 GIA**（电信）：中国电信下一代承载网，GIA 是其中最高端的级别，延迟低、稳定性强，被很多人视为电信回程的"天花板"。

- **CMIN2 / CMI**（移动）：中国移动的优质回程线路，移动用户访问香港的低延迟首选。

## 回程优化到底意味着什么：技术层面说清楚

这块展开讲一下，因为搜索"香港 VPS 回程"的人，多半是想搞明白线路背后的门道。

**去程 vs 回程，不对称是常态**

国际互联线路存在一个很现实的问题：去程和回程往往不走同一条路。很多便宜香港 VPS 的去程确实走了 CN2，看起来测试 IP 的 ping 值也不错，但回程走的是普通 163 骨干网或者国际 BGP 出口，一到晚高峰就拥堵、丢包。这就是为什么有些 VPS "测速好看，用起来难受"。

**三网分别优化 vs 单网优化**

有些商家只优化了电信回程（走 CN2 GIA），联通和移动走普通线路。对单网用户够用，但如果你的访客覆盖三网，那联通和移动用户体验会打折扣。GoMami 的做法是三网分别走各自的精品回程：电信回 CN2、联回 9929、移回 CMIN2，谁来了都走自己的"VIP 通道"。

**延迟为什么能压到 50ms 以内**

香港到大陆的物理距离很近，理论上 CN2 GIA 线路到广东周边能压到 10-20ms，到华北、华东也普遍在 30-50ms 区间。GoMami 官方给出的 RTT < 50ms 是一个相对保守的覆盖性承诺，实际在华南地区会更快。第三方实测数据显示，其香港节点三网延迟普遍在 30-50ms 之间，晚高峰也能维持稳定。

**DDoS 防护的附加价值**

回程优化解决了"快"的问题，DDoS 防护解决的是"活"的问题。GoMami 默认提供基础防护，最高可升级到 600Gbps 的清洗能力——这个量级在香港 VPS 里属于比较高的配置，对游戏服、跨境电商这类容易被攻击的场景很有价值。

## 怎么自己验证回程质量

买之前或买之后，都建议亲手测一下回程，别只信宣传。几个常用方法：

**用 Looking Glass 看路由**

GoMami 提供了 Looking Glass 测试地址，可以直接 ping 各节点的测试 IP，看实际延迟和路由跳数。香港 Turin 测试 IP 是 `103.73.220.46`，Peak X5 是 `103.238.130.91`，Pulse 是 `103.238.130.93`。

**回程路由测试脚本**

拿到 VPS 后，SSH 登录跑一下业内常用的回程测试脚本（比如 nexttrace 或 mtr），能直观看到三网回程分别走的什么线路。如果电信回程出现 `59.43.x.x`（CN2 GIA 的标志性 IP 段）、联回出现 `9929`、移回出现 CMI 节点，就说明三网回程优化是到位的。

**晚高峰测速**

白天测速好看不算数，真正考验是晚上 20:00-23:00 的大陆出口高峰期。这个时段跑一次 speedtest 和 ping，如果延迟稳定在 50ms 以内、速度没有大幅掉档，那这台 VPS 的回程质量就是合格的。
